# WittyMart Project Documentation

## Project Overview
**WittyMart** is a smart shopping platform designed to provide users with a seamless and enjoyable online shopping experience. The platform offers a wide range of products across various categories, including electronics, fashion, home & living, beauty & health, sports & outdoors, and more. This project includes multiple pages and features that allow users to browse products, manage their accounts, and interact with the platform.

## Features
- **User Registration and Login**: Users can create accounts and log in to access personalized features.
- **Product Categories**: Organized product categories for easy navigation.
- **Shopping Cart**: Add products to the cart and view the total cost.
- **Responsive Design**: Optimized for both desktop and mobile devices.
- **Dark Mode**: Toggle between light and dark themes.
- **Newsletter Subscription**: Users can subscribe to receive updates.
- **Contact Form**: Users can send messages or inquiries via the contact page.
- **Dynamic Navigation**: Sidebar and navigation bar for easy access to pages.
- **Footer Links**: Quick access to important pages like Terms, Privacy Policy, and Contact.

## Project Structure
The project is organized into the following files and directories:

```
Root Directory
│
├── index.html          # Homepage
├── welcome.html        # Welcome page after login
├── home.html           # Registration/Login page
├── shop.html           # Shop page with product listings
├── cart.html           # Shopping cart page
├── about.html          # About Us page
├── contact.html        # Contact Us page
├── terms.html          # Terms and Policies page
├── breadcrumbs.html    # Category-specific product listings
├── style.css           # Main stylesheet
├── script.js           # JavaScript for interactivity
├── images/             # Directory for images
└── README.md           # Project documentation (this file)
```

## File Descriptions

### HTML Files
- **`index.html`**: The homepage with an introduction to WittyMart and featured products.
- **`welcome.html`**: Displays a welcome message after successful login or registration.
- **`home.html`**: Contains forms for user registration and login.
- **`shop.html`**: Lists products available for purchase.
- **`cart.html`**: Displays items added to the shopping cart and the total cost.
- **`about.html`**: Provides information about WittyMart's mission and offerings.
- **`contact.html`**: Includes a contact form and embedded Google Maps for location.
- **`terms.html`**: Details the privacy policy, terms & conditions, and return policy.
- **`breadcrumbs.html`**: Displays products filtered by categories.

### CSS File
- **`style.css`**: Contains all the styles for the project, including responsive design, dark mode, and animations.

### JavaScript File
- **`script.js`**: Handles interactivity, such as toggling themes, sidebar navigation, form validation, and dynamic cart updates.

### Images
- **images**: Contains all the images used in the project, such as product images, logos, and banners.

## Key Functionalities

### 1. User Authentication
- Users can register and log in using the home.html page.
- After successful login, users are redirected to the welcome.html page.

### 2. Product Browsing
- Products are categorized for easy navigation.
- Users can view product details and add items to the cart.

### 3. Shopping Cart
- Users can add products to the cart and view the total cost on the cart.html page.

### 4. Responsive Design
- The platform is fully responsive, ensuring a smooth experience on both desktop and mobile devices.

### 5. Dark Mode
- Users can toggle between light and dark themes using the theme toggle button.

### 6. Contact Form
- Users can send inquiries via the contact form on the contact.html page.

### 7. Footer Links
- Quick access to important pages like Terms, Privacy Policy, and Contact.
